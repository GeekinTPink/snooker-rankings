## Memory bootstrap (project rule)

When starting a new session in this repo, always do the following before any work:

- Read `SOUL.md`
- Read `USER.md`
- Read `memory/YYYY-MM-DD.md` for **today** and **yesterday** (create if missing)
- Read `MEMORY.md`

During the session:

- If the user says "remember this" or a decision/constraint will matter later, write it down immediately:
  - Short-lived, chronological notes → `memory/YYYY-MM-DD.md`
  - Stable conventions/decisions → `MEMORY.md`

Constraints:

- If the user requests "只检查不修改" (check only), do not edit any code or data files.
- Default output language is Chinese (Simplified) unless the user requests otherwise.
