## Heartbeat checklist (lightweight)

When pinged for a heartbeat, do the minimum useful checks:

- `git status` for unexpected changes/untracked artifacts
- If recent work was done, ensure key decisions are written to:
  - `memory/YYYY-MM-DD.md` (raw session notes)
  - `MEMORY.md` (stable conventions/decisions)

Stay quiet (reply `HEARTBEAT_OK`) if nothing needs attention.
